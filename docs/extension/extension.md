## Frequently asked

### Which browsers does it support?

Chrome, Edge and every other Chromium-based browser, plus Firefox and Safari. It is built on Manifest V3, the current extension platform. The on-device AI models need a browser that can reach your graphics processor, which Chromium browsers do today; everywhere else the extension answers with askFinz's cloud models and tells you so.

### Do the models really run on my own machine?

On a device with a compatible graphics processor, yes — and what you ask them never leaves it. On a device without one, the extension uses askFinz's cloud models instead and tells you which answered. You can check your device in one tap before installing.

### What can it see?

It works with the page you're actively on, when you ask it to. It needs browser permissions to do that, and it's bound to your account with a credential scoped to you alone.

### Is it in the Chrome Web Store?

The listing is queued. While askFinz is in private access we send install links directly to people on the waitlist.

### How is this different from using askFinz in a tab?

The extension is the side door — it's for working with whatever page you're already on. The full platform, with agent fleets, file editing and dashboards, lives in the workspaces.
